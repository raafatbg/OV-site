# Directives

SOPs (Standard Operating Procedures) written in Markdown.

Each directive defines:
- **Goal** — what the task accomplishes
- **Inputs** — what data/context is needed
- **Tools/Scripts** — which `execution/` scripts to call
- **Outputs** — what gets produced (deliverables or intermediates)
- **Edge cases** — known gotchas, API limits, timing notes

Directives are living documents. Update them as you learn.
